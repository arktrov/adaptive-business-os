# Rights and provenance

UNKNOWN, REVIEW_REQUIRED, CLEARED, RESTRICTED and NOT_ALLOWED remain distinct. Public URL access is never clearance. CLEARED requires authority, reference and basis from an explicit reviewed license/rights input. Native original scene specifications default to REVIEW_REQUIRED; no implicit commercial-rights approval is made.

Provenance includes source/creation origin, references, provider/model/request when applicable, timestamps, prompt/spec hash, package/beat/claim links, classification and disclosure. Original native compositions include evidence and pinned policy references. Generated media must be ILLUSTRATIVE. Sanitized recovery records exclude transport headers and private reasoning.

Costs remain null/UNKNOWN when absent; attempts carry business, job, model, requirement and workflow dimensions. Usage and reported cost are retained. No invented zero monetary cost.
