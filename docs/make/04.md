## Purpose

Generate Short 1 narration with character timestamps, upload the audio and record its timing.

## Trigger

Production C=Script Drafted OR Assets Ready, AND S short_script_1 exists AND AF Voice Timing JSON does not exist; limit 1.

## Inputs

Production/Story IDs, Short 1 script, original production values and fixed configured voice.

## Outputs

MP3 in ShortsAudio; Voiceover Asset row; AF alignment JSON; Production Voice Ready (or preserves Assets Ready); matching Story Voice Ready.

## Google Sheets dependencies

Production Pipeline read; update A:Z and AF. Asset Library append; Story Pipeline lookup by ID limit 1 and status update. Later production fields not mapped by this update need preservation checks.

## Google Drive dependencies

D-AUDIO / ShortsAudio upload, with production/short/version title and voice.mp3 filename. Physical folder/account IDs retained only in ignored raw export.

## Data structures

ElevenLabs JSON response audio_base64 plus alignment; alignment serialized with characters[], character_start_times_seconds[], character_end_times_seconds[]. Asset duration is rounded last end time ×1000.

## Status transitions

Script Drafted → Voice Ready, or Assets Ready stays Assets Ready; Story → Voice Ready; new audio Asset → Generated – Needs Review.

## APIs / providers

HTTP POST ElevenLabs /v1/text-to-speech/{configured_voice}/with-timestamps?output_format=mp3_44100_128; eleven_v3, speed=1, use_speaker_boost=false, normalization=auto; configured secret reference. Google Drive and Sheets.

## Error handling

HTTP stopOnHttpError=true, response parsed; no explicit recovery route. Audio decode/playability and timing-to-script equality are not tested here.

## Retries / idempotency

AF absence guards completed timing only. Provider call/upload/Asset insert before AF write can replay and duplicate charges/files/rows. No enforced asset idempotency; literal V1 in audio ID is a label, not a lock.

## Upstream scenarios

03, or an external Assets Ready row without timing.

## Downstream scenarios

05 requires Voice Ready; 06 can consume Assets Ready with completed AF timing.

## Known special cases

Late voice generation preserves an existing Assets Ready status. Audio Asset ID AUD-{ProductionID}-SHORT1-V1. Cost=0 is a placeholder, not measured provider cost; subscription/license description is legacy metadata, not independently verified rights.

## Business logic to preserve

Actual Short 1 script, timestamp precision and character ordering, audio provenance and file linkage, late-voice status special case.

## Technical implementation to replace later

Provider abstraction, usage capture, durable call checkpoint and immutable audio revision; validate audio/timing before stage completion.

## Required validation

T07: partial failure at each write; audio/timing/script equality; late voice state; duplicate version and zero-cost semantics.
