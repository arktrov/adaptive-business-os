## Purpose

Plan Short 1 visuals and generate AI images or create official-source retrieval requests.

## Trigger

Production C=Voice Ready, S and J exist, B equals the fixed V004 Story ID; limit 1. This is not enabled by configuration for arbitrary V005 stories.

## Inputs

Production identity, title, Short 1 hook/script, angle, visual direction, source guardrails and disclaimer. J Scene Plan must exist but is not supplied in the model prompt.

## Outputs

AE AI Shot Plan JSON (raw model JSON); per-shot image Asset rows/files or official-source placeholder Assets; eventual Production Visual Assets Pending QA.

## Google Sheets dependencies

Production read and AE/C cell updates. Asset Library append including literal version IDs, review status, AI flag and QA Pending.

## Google Drive dependencies

D-VISUAL / VisualsShorts: generated PNG upload for AI branch. Official branch has no file until 05B.

## Data structures

Strict arktrov_short_visual_plan: story_id, production_id, visual_plan_status, total_duration_seconds, shots[]. Shot fields: shot_number, start_second, end_second, visual_type, visual_purpose, generation_prompt, motion_instruction, on_screen_text, source_requirement, fact_caution, aspect_ratio. Make ParseJSON matches visual_purpose. No schema enum/range enforces prompt's ready/9:16/type/timing rules.

## Status transitions

Voice Ready → Visual Assets Pending QA only on a processed shot whose end_second equals total_duration_seconds. Image Assets Generated – Needs Review; source Assets Source Required; all QA Pending.

## APIs / providers

OpenAI gpt-5.6-sol planning, no web tools, max_output_tokens=6000/store=false. gpt-image-2 GenerateImage: one 1152×2048 high-quality opaque PNG. Drive and Sheets.

## Error handling

No error route, unknown-type fallback or all-shot barrier. Final-shot status does not prove all assets exist or passed QA.

## Retries / idempotency

Asset Idempotency Key contains deterministic IMG/SRCVIS-{ProductionID}-SHORT1-SHOTn-V1, but AddRow never checks it. Partial run/retry can regenerate and append duplicates.

## Upstream scenarios

04 Voice Ready, restricted to V004.

## Downstream scenarios

05B for official Source Required assets; external/unrepresented readiness decision before 06.

## Known special cases

Both branches require shot_number>1: Shot 1 is excluded with no supplied producer. ai_video and diagram route to static PNG generation. Prompt contains magnetar, vacuum-birefringence and prism-specific cautions; these are V004 content rules, not generic defaults. 7–9 consecutive shots around 55s, changes 5–8s, final end=total and no overlap are prompt-only. ParseJSON uses result while AE saves raw_result; verify actual connector representations.

## Business logic to preserve

Every visual supports narration, source/AI distinction, provenance/rights caution, mobile 9:16 composition and caption safe space. Never fake authentic telescope footage, measurements or scientific proof. Keep per-shot motion/text/caution and source requirements, even if current filenames/notes encode them.

## Technical implementation to replace later

Brand/story-scoped visual rules, typed timeline validated against voice, explicit initial-shot producer, actual capability choice for video vs image, immutable deduplicated assets and readiness aggregation.

## Required validation

T08: V005 filter exclusion; missing Shot 1; unexpected visual_type; ai_video parity; result/raw_result; malformed/overlapping plan; voice duration; partial retry and final-shot readiness.
