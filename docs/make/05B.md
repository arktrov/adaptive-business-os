## Purpose

Find one verifiable reusable official visual for a pending scene and upload it with provenance.

## Trigger

Asset I=Source Required, G File Link does not exist, B equals the same fixed V004 Story ID; limit 1.

## Inputs

Asset/Story IDs, scene, required visual description and editorial/factual restrictions from Notes.

## Outputs

Downloaded official file in D-VISUAL and updated Asset provenance, rights, review/QA status; or Source Retrieval Failed/Blocked with error.

## Google Sheets dependencies

Asset Library read/update A:V mapping, including File Link, License/Rights, Notes, Public URL, Source ID, QA Status and Last Error.

## Google Drive dependencies

D-VISUAL / VisualsShorts official file upload. Returned webViewLink becomes Asset File Link.

## Data structures

Strict retrieval output and matching Make parser: approved, asset_id, source_id, publisher, source_page_url, direct_file_url, rights_status, license_url, attribution_required, attribution_text, file_extension, selection_reason, error.

## Status transitions

Source Required → Retrieved – Needs Review + Pending when approved and direct URL exists; router fallback → Source Retrieval Failed + Blocked. No automatic failed→retry transition.

## APIs / providers

OpenAI gpt-5.6-luna, web_search_preview medium, reasoning medium, max_output_tokens=2500, store=false; HTTP unauthenticated download; Google Drive and Sheets.

## Error handling

Fallback catches nonapproved/missing direct URL business outcome. Download HTTP stopOnHttpError=true; an HTTP/upload exception does not reach the router fallback because no explicit error route exists.

## Retries / idempotency

Fixed asset row update, but successful download/upload before row completion can duplicate Drive files. Failed rows are not automatically selected again. No server-side ID/URL/MIME/rights assertion independent of model.

## Upstream scenarios

05 official_source branch.

## Downstream scenarios

External asset QA/readiness; 06 reads assets by Story ID + File Link.

## Known special cases

Approved comparison is Make boolean Yes. Filename/title combines Asset ID + extension and downloaded filename; extension duplication requires validation against observed .jpg.jpg legacy artifacts. Rights text concatenates three strings without separators. Success Public URL=direct file, failure Public URL=source page. Model returns asset_id but update targets original row without equality guard.

## Business logic to preserve

First-party NASA/ESA/observatory/university/government/arXiv/original publisher sources; reject stock/social/blog/Wikipedia/reposts/AI/unknown rights; prefer explicit public domain or reusable CC; never invent URLs; fail closed if authenticity, rights or direct link cannot be established. Scientific figures unaltered with original attribution, no exaggerated scientific proof.

## Technical implementation to replace later

Typed provenance with separate page/file/license/attribution fields, file validation and safe download boundary, deterministic identity/rights checks, resumable asset retrieval.

## Required validation

T09: false/missing URL, HTTP404, wrong MIME, missing rights, mismatched asset_id, duplicate extension, upload/row crash, required attribution preservation.
