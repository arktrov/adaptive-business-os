# Controlled voice generation

The ElevenLabs adapter uses the official [Create speech contract](https://elevenlabs.io/docs/api-reference/text-to-speech/convert): one POST returning audio bytes, with configured model, voice reference, output format and approved settings. No SDK retries, redirect following, voice listing, model lookup or additional provider call. Request identity includes exact approved text and immutable business profile snapshot. The normal AssetService admits one attempt per plan/voice requirement; the local runner also consumes an exclusive persisted local claim before dispatch. Errors require human review, never automatic retry. Missing credentials stop before consumption and do not undo profile approval.

V005 is configured only in an ignored local permit: selected Script v4 and Package v4, plan hash, profile ID/hash, exact request hash, code hash, acceptance-log hashes and human source reference. A matching immutable asset_voice_authorization record is required. Generic core has no ARKTROV/ElevenLabs routing default.

The user confirmed the existing voice, provider-native category generated, English metadata, name/description and personally reviewed preview in the approval attachment. These are human-reported provider verification, not a successful Codex metadata lookup. Historical Make provenance remains separate. Generated Voice Design maps to CUSTOM, not CLONED; explicit human authorization for this existing provider voice and approval references are retained. [ElevenLabs voice types](https://elevenlabs.io/docs/overview/capabilities/voices) distinguish generated Voice Design from voice clones. Original candidate remains immutable; enriched candidate revision 2 and human APPROVED revision 3 are appended.

Response order: receive binary audio and allowlisted metadata; sanitize; seal and fsync an exclusive local recovery JSON with readback hash verification; persist and verify asset_response in PostgreSQL; decode/QA; persist immutable VoiceAsset and outcome; export and verify the MP3; append a new manifest. A database or local decoder failure leaves the original response recoverable (database and/or local spool). Partial transport is captured but cannot pass. No authorization headers, credentials or provider error bodies are retained. HTTP errors use safe codes; request ID and character usage are retained when actually available; monetary cost remains unknown unless reported. Input character count is not represented as billed usage. Content/byte hashes and received timestamps are stored. Failed attempts remain immutable.

Audio QA decodes actual MP3 through configurable local FFMPEG_PATH/FFPROBE_PATH, checks codec, 44.1 kHz, 128 kbit/s, duration, PCM clipping and silence. The current Windows environment uses existing FFmpeg/ffprobe executables read-only; no renderer code or worker is invoked. MP3 validation stays behind a decoder boundary and is rechecked on repository/manifest admission. Technical QA never claims perceptual/final review. Subtitle timings remain unresolved: this binary endpoint does not supply alignment. Existing punctuation and text are sent byte-identically; no audio tags, rewritten wording or unsupported pause cues are injected. Audio-plan cues remain retained for later production review.

Manifest revisions reference a technically valid voice even while rights are REVIEW_REQUIRED. They do not silently clear rights or the other audio/visual requirements. Publication HOLD TRUE, RELEASE_ALLOWED FALSE. No render or publishing.

Tests need local PostgreSQL plus FFMPEG_PATH and FFPROBE_PATH pointing to real audio-capable executables. Synthetic PCM is encoded locally to MP3 for QA tests; test transports are injected and never call ElevenLabs. Local recovery exports and permits stay gitignored.

If local spool persistence fails, PostgreSQL response capture is still attempted before stopping with LOCAL_RESPONSE_RECOVERY_FAILED. Conversely, a database failure leaves the verified local spool. No system can guarantee preservation if both independent storage paths fail; such failures must stop and never authorize a repeat call automatically.
